# Media workspace

- `screenshots/` — raw or working product captures.
- `videos/` — recordings and exports.
- `diagrams/` — journeys, architecture and explanatory graphics.
- `logos/` — approved and proposed identity assets.
- `approved/` — publication-ready copies only.

Register every asset in [`Media-Inventory.md`](Media-Inventory.md). Never place real patient data, credentials or administrative secrets in media. Moving an asset into `approved/` requires claim/privacy review.
