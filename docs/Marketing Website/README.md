# THIQA marketing website workspace

Use [`MarketingWebsite.md`](MarketingWebsite.md) as the entry point. Each numbered folder owns one kind of work:

1. `01-governance` — rules, decisions and claim control.
2. `02-strategy` — market, positioning, audience and method.
3. `03-website-plan` — sitemap, journeys, demo, forms and funnel.
4. `04-content` — page-ready English and Arabic copy.
5. `05-media` — screenshots, videos, diagrams and approvals.
6. `06-technical` — architecture, security, operations and deployment.
7. `07-delivery` — readiness and launch control.

`committee` is only for committee outputs. `archive` contains immutable historical originals.
